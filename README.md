# WebLab Explorer — Interactive Web Technology Learning IDE

A responsive, browser-based learning environment and code editor built for **Web Technology Module 1** (`WEB Mod1AzDOCUMENTS.in.pdf`).

## Features

- **100% Complete PDF Curriculum Coverage**: Every single example, figure, code listing, and reference table across all 44 pages of Module 1 (Chapter 1: HTML & Chapter 2: CSS).
- **Three Independent Code Editors**: Genuine editable `index.html`, `style.css`, and `script.js` panes powered by Monaco Editor with syntax highlighting, line numbers, formatting, and find/replace.
- **Isolated Live Browser Preview**: Instant sandboxed preview with responsive viewport simulator (Mobile 375px, Tablet 768px, Laptop 1024px, Desktop Fluid), zoom controls, and pop-out preview.
- **Embedded Console & Output Terminal**: Live runtime capturing of `console.log`, `console.info`, `console.warn`, `console.error`, and uncaught JavaScript errors with level filters.
- **Project File Explorer & Curriculum Navigator**: Seamless switching between the `web-technology-lab/` file system and the structured chapter/topic curriculum tree.
- **Interactive Reference Tables**: Searchable, filterable explorers for all 10 source reference tables (Relative Referencing, Semantic Elements, Character Entities, CSS Properties, Color Formats, Units, Selectors, Box Model, and Typography).
- **Local Persistence & Export**: Working drafts saved automatically to `localStorage` per example; download individual files or export the complete project as a standard ZIP with README.
- **Keyboard Shortcuts**: `Ctrl + Enter` (Run), `Ctrl + S` (Save draft), `Alt + N` (Next example), `Alt + P` (Previous example).

## Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
